# بوت مجتمع Discord عربي

بوت قابل للتوسعة لإدارة مجتمع Discord، مبني على `discord.js` ويحتاج Node.js 20 أو أحدث.

## الميزات

- ترحيب للأعضاء الجدد وردود تلقائية قابلة للتعديل.
- تذاكر خاصة بزر فتح وإغلاق، مع صلاحيات لصاحب التذكرة وفريق الدعم.
- إشراف: حظر، إلغاء حظر، طرد، إسكات مؤقت، إنذارات وعرض الإنذارات.
- حذف رسائل، إرسال إعلان باسم البوت، ومعلومات السيرفر.
- سجل لإجراءات الإشراف عند تعيين قناة السجلات.

## التشغيل

1. أنشئ تطبيقًا وبوتًا من [Discord Developer Portal](https://discord.com/developers/applications) وانسخ التوكن. لا تشارك التوكن.
2. فعّل **Server Members Intent** و**Message Content Intent** من صفحة Bot.
3. انسخ `.env.example` إلى `.env` وأدخل `DISCORD_TOKEN` و`CLIENT_ID` و`GUILD_ID`.
4. من مجلد المشروع شغّل `npm install`، ثم `npm run deploy` لتسجيل أوامر سيرفر التجربة، وبعدها `npm start`.
5. ادعُ البوت إلى سيرفرك بالصلاحيات اللازمة، ثم استخدم `/setup` في قناة لوحة التذاكر.

## الإعداد

عدّل `config.json`: معرّف قناة الترحيب والسجلات، فئة التذاكر، ورتبة الدعم. اترك أي قيمة فارغة لتعطيل الميزة المرتبطة بها. للحصول على المعرفات فعّل Developer Mode في Discord ثم اختر Copy ID.

رتبة البوت يجب أن تكون أعلى من الرتب التي يحتاج إدارتها. امنحه أقل الصلاحيات اللازمة. أوامر Discord الإدارية تقيّد تلقائيًا حسب الصلاحيات. يلزم تفعيل intents المذكورة حتى تعمل أحداث الترحيب والردود.

تُحفظ الإنذارات محليًا في `src/data/warnings.json`. التذاكر قنوات Discord مباشرة. احتفظ بنسخة احتياطية من ملف الإنذارات.

هذه نسخة تأسيسية تغطي الوظائف الشائعة. لا تتضمن لوحة ويب أو قاعدة بيانات مستضافة أو فلترة متقدمة لمكافحة السبام أو اقتصادًا ومستويات أو نسخًا احتياطيًا آليًا. الرد التلقائي يبحث عن نص المحفز حرفيًا؛ اجعل المحفزات محددة لتقليل الردود غير المقصودة.
